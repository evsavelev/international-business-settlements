# Международные расчёты для бизнеса

Одностраничный коммерческий сайт для заявок на оплату зарубежных поставщиков,
получение платежей из-за рубежа и другие международные коммерческие расчёты.

## Что реализовано

- адаптивный B2B / trade finance интерфейс;
- квалифицирующая форма с передачей заявки в мессенджер;
- услуги, порядок работы, доверие, независимые отзывы, кейсы и FAQ;
- SEO-метаданные, структурированные данные, robots и social preview;
- проверенные контакты «Биток-консалтинг».

Возможность конкретной операции подтверждается только после проверки сделки.
